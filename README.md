# 🤖 AI Chatbot - Flask + Ollama + PDF

WhatsApp style AI chatbot with Dark/Light Mode and PDF support

## ✨ Features
- 🌙 Dark Mode / ☀️ Light Mode Toggle
- 📄 PDF Upload & Ask questions from PDF
- 💾 Chat History Saved automatically
- 🗑️ Clear History Button
- 🌍 Works in Marathi, Hindi, English

## 🛠️ Tech Stack
Flask, Ollama, Llama3.1:8b, PyPDF2

## 🚀 How to Run Locally
1. Install [Ollama](https://ollama.com) and run: `ollama pull llama3.1:8b`
2. Install requirements: `pip install -r requirements.txt`
3. Run: `python app.py`
4. Open: `http://localhost:5000`

## 📌 Note
Ollama needs to be running on your PC for this to work.
